# Fireflies clone — frontend

Next.js 16 (App Router, TypeScript, Tailwind v4, TanStack Query). See the [root README](../README.md) for the full
setup, architecture and API overview.

```bash
cp .env.example .env.local   # NEXT_PUBLIC_API_URL=http://localhost:8000
npm install
npm run dev                  # http://localhost:3000
npm run build && npm start   # production
npm run lint
```
